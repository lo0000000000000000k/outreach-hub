# Outreach Hub

Capture → enrich → Google Sheet, plus a dashboard and a daily automation. Built for 91 Agency's client outreach.

- `app/`: dashboard (Next.js), API routes
- `lib/`: sheet, dedupe/merge, page cleaning, website scan, Apollo, activity log
- `extension/`: Chrome/Edge capture extension
- `tests/`: `npm test` (offline)

Setup: see **SETUP.md**.
